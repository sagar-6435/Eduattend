🚀 QUICK START (15 MINUTES)
═══════════════════════════════════════════════════════════════════════════

1. Start MongoDB:
   docker run -d -p 27017:27017 --name eduattend-db mongo:latest

2. Start Backend:
   cd backend && npm install && npm run dev

3. Start AI Service:
   cd ai-service && python -m venv venv && pip install -r requirements.txt && python app.py

4. Start Mobile App:
   cd mobile-app && npm install && npm start
